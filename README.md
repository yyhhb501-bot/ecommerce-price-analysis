# ecommerce-price-analysis

帮朋友的服装店（主打 Polo 衫和牛仔裤，主要走微信视频号，客群偏中老年）做的
一个竞品价格分析。抓了淘宝、拼多多、抖音、微信视频号四个平台的同类商品，
看看价格带分布、价格和销量之间的关系，最后给出一套定价建议。

## 跑出来什么

- 四个平台的价格带分布，以及各平台价格水平对比
- 价格和销量的相关性（两个品类都是负相关，价格越低越好卖）
- 核心价格带识别，再拆成引流款 / 主推款 / 利润款三档定价
- 一个 A/B 测试框架，用来验证降价到底划不划算

完整的分析结果看 `output/report.md`，图表在 `output/figures/`，汇总表是
`output/项目成果分析.xlsx`。

## 技术栈

Python 为主，pandas + scipy 做分析和统计，MySQL 存数据，Tableau 出图，
爬虫用 requests + BeautifulSoup。

## 怎么跑

先装依赖：

```bash
pip install -r requirements.txt
```

第一次要先在 MySQL 建库：

```bash
mysql -u root -p < sql/01_create_schema.sql
```

然后一条命令跑完整流程：

```bash
python main.py
```

流程是：爬数据 -> 清洗入库 -> 分析 -> A/B 测试 -> 出图表和报告。

## 目录

- `crawlers/` 四个平台的爬虫（淘宝 / 拼多多 / 抖音 / 微信视频号）
- `analysis/` 清洗、ETL、分析、A/B、可视化、报告生成
- `sql/` 建表脚本和分析用的 SQL
- `tableau/` Tableau 的 .hyper 提取和搭建说明
- `data/` 原始数据和清洗后的数据
- `output/` 图表、报告、Excel

## 关于数据

这几个平台都有登录和签名风控，直接抓基本会被拦，所以爬虫能抓到多少算多少，
抓不到的部分用参考数据补上（`data_source` 字段会标 `crawled` 还是 `reference`）。
A/B 测试的数据是模拟的，主要是演示流程，接上真实流量日志就能用。

所以这套东西更多是方法和流程的演示，数字别当真，真要用得接正规数据源。

## 一点结论

- Polo 衫核心价格带 20–39 元，牛仔裤 40–59 元
- 价格和销量明显负相关
- 微信视频号在四个平台里客单价最高，中老年用户确实更看重品质
- A/B 测试下来，降价能拉转化率（+36%），但毛利掉得更多（-30%），所以引流款
  只能限时限量做，日常还是主推原价
