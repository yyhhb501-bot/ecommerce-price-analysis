# 电商竞品价格与销量分析（Polo 衫 & 牛仔裤）

对淘宝、拼多多、抖音三个平台的同品类商品做价格与销量分析，输出价格带分布、
价格-销量相关性、核心价格带识别与可执行定价建议。

## 核心结论

| 品类 | 价格-销量 Pearson | 核心价格带 | 引流款 | 主推款 | 利润款 |
|---|---|---|---|---|---|
| Polo 衫 | -0.689 | 20–39 元（占 51.8% 销量） | 39 元 | 58 元 | 76 元 |
| 牛仔裤 | -0.782 | 40–59 元（占 43.8% 销量） | 58 元 | 79 元 | 112 元 |

> 两个品类的价格-销量均呈显著负相关：价格越低、销量越高。
> 完整报告见 [`output/report.md`](output/report.md)。

## 环境与运行

- Python 3.13（64 位）
- 依赖安装：`pip install -r requirements.txt`
- 一键运行：`python main.py`

流程：真实抓取 → 备用数据兜底 → 清洗入库 → 分析 → 可视化 → 报告。

## 数据说明（重要）

- **真实抓取**：淘宝（`s.taobao.com`）、拼多多（`mobile.yangkeduo.com`）、
  抖音商城（`haohuo.jinritemai.com`）均存在登录态 + 签名（`sign`/`anti-content`/`X-Bogus`）
  风控，未登录请求会被重定向到登录页或返回验证码/JS 空壳页，无法稳定取到商品数据。
  本项目的爬虫已实现完整请求与解析流程，并在 `data/raw/crawl_report.json`
  中如实记录了每个平台被拦截的状态。
- **备用数据**：为跑通完整分析流程，`generate_reference_data.py` 按公开渠道可查的
  常见价格带与销量量级生成参考数据，记录中 `data_source='reference'` 与真实抓取
  `'crawled'` 严格区分。
- **结论性质**：本报告结论为方法与流程演示，不构成真实经营建议。若要用于真实经营，
  请接入合规的数据接口（如平台开放 API / 已授权数据源）后重新跑。

  结合评价数量等替代指标。

  撰写定价建议报告。

  建议 Polo 衫引流款定价 39 元、主推款 58 元、利润款 76 元（牛仔裤分别为 58/79/112 元）；
  价格-销量相关系数 Polo 衫 -0.689、牛仔裤 -0.782。
